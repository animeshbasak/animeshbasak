## About

Lead Frontend Engineer with 8 years on high-traffic consumer products: hotels booking at MakeMyTrip, merchant payments at Paytm, and the Airtel Thanks app (150M+ MAU), where I lead a squad of 5–7 engineers.

I own journeys end to end: React and TypeScript front ends on mobile web, desktop and React Native, the Backend-for-Frontend (BFF) layer behind them, and Spring Boot services where needed. I ship with AI: MCP-integrated delivery workflows at work, and open-source developer tools outside it.
